# Getting Started

Run the server from `src/amqp-go`. The module needs Go 1.25.1 or newer.

## One process

```bash
cd src/amqp-go
go run ./cmd/amqp-server
```

The process listens on port 5672 and stores data in `./data`.

Generate a config file, then start with it:

```bash
go run ./cmd/amqp-server --generate-config config.yaml
go run ./cmd/amqp-server --config config.yaml
```

Build a binary:

```bash
go build -o amqp-server ./cmd/amqp-server
./amqp-server --version
```

## Publish one message

With the server running:

```bash
pip install pika
```

```python
import pika

connection = pika.BlockingConnection(pika.ConnectionParameters("localhost"))
channel = connection.channel()
channel.queue_declare(queue="hello")
channel.basic_publish(exchange="", routing_key="hello", body="Hello World!")
print(" [x] Sent 'Hello World!'")
connection.close()
```

More clients are in [Demo](/demo).

## Environment variables

Any config key can be overridden with `AMQP_<section>_<key>`:

```bash
AMQP_NETWORK_PORT=15672 go run ./cmd/amqp-server --config config.yaml
AMQP_STORAGE_PATH=/var/lib/amqp go run ./cmd/amqp-server
AMQP_SERVER_LOGLEVEL=debug go run ./cmd/amqp-server
```
